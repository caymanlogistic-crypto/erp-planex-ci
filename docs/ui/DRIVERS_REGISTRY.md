# Реестр водителей — действующая адаптация

`/erpv2/company/drivers` использует семейство `registry` из каталога `approved-components.json`: общий partial шапки, CSS/JS оболочки, поиск, выбор сортировки, сброс, закрепление панели/thead и типографику данных. Локальный `drivers-registry.css` содержит только геометрию предметных колонок.

Сохранены восемь колонок: ID, ФИО, контакты, почта, паспорт, водительское удостоверение, СНИЛС, файлы. На 390 px сохраняется таблица с внутренней горизонтальной прокруткой; на 1280/1920/3840 px колонки помещаются в рабочую рамку. Длинные ФИО и вторичные значения доступны целиком через общий `title`; исходные значения участвуют в поиске. Нулевое количество файлов остаётся `0`, отсутствие значения — `—`.

По умолчанию используется существующая сортировка по дате добавления (ID убывает). Алфавитная сортировка использует ФИО. Поиск и сортировка восстанавливаются при повторном открытии; общий серверный `RegistryUiStateScope` учитывает account, membership, компанию и effective права. Общая кнопка «Сбросить фильтр» стоит первой справа перед сортировкой и поиском и возвращает начальные значения. Устаревшая глобальная запись состояния водителей в sessionStorage отключена.

Сохранены форма создания и существующие endpoints просмотра, редактирования, удаления, телефонов и документов. Двойное нажатие открывает карточку; клавиша Enter на строке даёт тот же результат. Контроллер и DriverService сохраняют действующую фильтрацию по правам; изменение не содержит миграций или записи бизнес-данных.

Проверки:

- `drivers_table_fit_contract_test.php` — общий контракт и восемь колонок.
- `drivers_registry_runtime_mysql_test.php` — настоящий bootstrap/controller/service/layout без fixture autoload, только disposable схема; данные после render неизменны.
- `drivers_registry_browser_test.mjs` — реальный общий CSS/JS и шрифты, varied synthetic данные, 390/1280/1920/3840, normal/hover/focus, поиск полного значения, алфавит, сброс/reload, создание/просмотр и пустое/ошибочное/неактивное состояния.
- Каталог, style guard и все зарегистрированные реестры повторно проверяются финальным LOCAL preflight.
