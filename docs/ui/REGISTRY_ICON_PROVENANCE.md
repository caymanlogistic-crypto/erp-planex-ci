# Происхождение иконок заголовков реестров

Для каждого нового или изменённого реестра `approved-components.json` требует `header_icon` с ролью `registry.page-head`, пакетом `@tabler/icons`, версией `3.48.0`, вариантом `outline`, именем и точным путём `app/View/components/tabler/outline/<name>.svg`. Каталог сверяет исходный SVG с закреплённым перечнем SHA-256 всех 5166 официальных контурных иконок в `tabler-outline-3.48.0.json` (SHA-256 перечня `effa1ed6d92b1d4fddec70099375fb0105fcd2e9741860b10c26315594e2a079`). Новые файлы извлекаются из официального архива пакета; произвольная геометрия и метаданные иного пака отклоняются.

Общий `assertRegistryVisualContract` сравнивает отрисованную геометрию с точным именованным исходником, размер, цвет и обводку. `registry_visual_gate.mjs` запускает зарегистрированные браузерные тесты и сверяет фактически выполненные ID страниц, поэтому путь к чужому тесту не даёт покрытие новой странице. Gate обязателен в LOCAL preflight и обоих CI маршрутах.

Закрытый исторический долг происхождения: `route-executors`, `trips-departures`, `finance-received-paid`, `logistics-closing-documents`, `drivers`. Для них сохраняется прежняя иконка только пока маршрут, путь и точные байты view совпадают с замороженными значениями в `ui_standard.py`. При изменении view долг закрывается добавлением полной проверенной записи `header_icon` и общей браузерной проверки. Этот список не расширяется автоматически.

Обе страницы используют именованные SVG из официального пакета [`@tabler/icons` 3.48.0](https://github.com/tabler/tabler-icons/tree/v3.48.0/icons/outline). Исходники находятся в `app/View/components/tabler/outline/`, уведомление MIT — в `app/View/components/tabler/LICENSE.txt`. Общий вывод выполняет `app/View/components/registry_tabler_icons.php`; геометрия SVG сохраняется, к корню добавляются только класс утверждённого размера и атрибуты доступности.

Свойства в шапке: 30 × 30 px, обводка 2, цвет `#7C4718`. `tests/helpers/registry_tabler_icon_contract.mjs` сравнивает имя, хеш файла, полную SVG-геометрию и вычисленные свойства в браузере. Контракт выполняется для обеих страниц на ширинах 390/1280/1920/3840 px. Негативная проверка заменяет путь SVG произвольной геометрией, сохраняя класс Tabler, и требует отказа контракта. Отдельный `tests/company_registry_runtime_browser_test.mjs` проверяет страницы через реальные маршруты, контроллеры и сервисы для OWNER и ограниченного пользователя, действия, права и неизменность бизнес-таблиц.
