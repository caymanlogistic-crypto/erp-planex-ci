# Статистика работы логистов

## Назначение

Раздел `/company/statistics/managers` показывает результат текущей компании и вклад каждого активного сотрудника с точной центральной ролью «Логист». В новых компаниях роль определяется системным ключом `logist`; в исторических компаниях без системного ключа — точным `normalized_name = логист`. Руководитель, «Логист+», «Логист (lite)» и остальные пользовательские роли могут иметь право открыть страницу, но их рейсы не включаются в расчёт. Межфирменного отчёта нет: данные всегда читаются только из tenant-базы выбранной компании.

## Что считается результатом

- Один рейс засчитывается в дату `waste_trips.actual_start_date`, когда его статус дошёл до `in_progress` («Вывоз начался»).
- Логист фиксируется по ответственному за рейс в момент первого попадания в статистику. Последующее переназначение не переписывает историческое авторство результата.
- При построении отчёта автор сверяется с текущим активным central membership: если сотрудник больше не имеет точной роли «Логист» в одном из двух допустимых технических представлений, его факты не входят ни в итог компании, ни в детализацию.
- Количество заявок и их вес берутся из `waste_trip_requests` (`COUNT` и `SUM(snapshot_mass_kg)`). Подтверждённая корректировка состава уже начатого рейса обновляет эти две величины.
- Завершение или отмена начатого рейса не удаляет результат; текущий статус используется для контрольных показателей.
- Исторические начатые рейсы заполняются миграцией 141 с признаком `is_backfilled=1`.

## Представления и фильтры

- По умолчанию: текущий календарный год по неделям, до сегодняшнего дня.
- «Неделя»: выбранная ISO-неделя с дневной динамикой.
- «Месяц»: выбранный календарный месяц с недельной динамикой.
- «Год»: выбранный год с переключением группировки по неделям или месяцам.
- «Свой период»: даты начала/окончания и группировка по дням, неделям или месяцам; максимальный интервал — 1096 дней.
- Метрики: рейсы, заявки, вес заявок.
- Фильтр по одному или нескольким логистам.
- Сравнение с предыдущей календарной неделей, месяцем, соответствующей частью прошлого года либо непосредственно предшествующим произвольным периодом.

Страница последовательно показывает KPI компании, общий график компании и логистов, рейтинг, точную матрицу значений по каждому периоду, итоговую сравнительную таблицу и расшифровку до исходного рейса.

## Доступ

Страница зарегистрирована ключом `company.statistics.managers` в `PageRegistry` и отображается в разделе «Статистика» управления ролями. Руководитель компании имеет системный доступ. Остальные сотрудники получают доступ через роль или персональное правило. Область данных рейсов (`all`, `own`, `none`) применяется дополнительно и не обходится страницей статистики.

## Схема и развёртывание

Физический источник фактов — `waste_trip_start_statistics`, миграция `141_create_waste_trip_start_statistics.sql`. GET страницы не применяет DDL: до контролируемой миграции интерфейс показывает безопасное сообщение ожидания схемы. Производственное применение выполняется отдельным guarded workflow `manager_statistics_141_production_migration.yml` после развёртывания точного canonical SHA и отдельного подтверждения владельца.
